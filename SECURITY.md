# Security

Please do not disclose vulnerabilities in public issues.

This repository is a fork maintained by [FlaBBB](https://github.com/FlaBBB), separate from the upstream Uizze hosted service and its support channels. GitHub private vulnerability reporting is not currently enabled on this fork, so report security concerns through the maintainer profile [https://github.com/FlaBBB](https://github.com/FlaBBB) instead of a public issue.

Include the affected file or component, reproduction steps, and potential impact. Relevant components include the local stdio MCP backend under `integrations/mcp/`, the one-command installer, the credential store in the user configuration directory, and the bundled skills.

Never include real Mobbin tokens, Google Fonts API keys, authorization codes, or other credentials in a report.
