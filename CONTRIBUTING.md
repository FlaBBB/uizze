# Contributing

This fork welcomes focused fixes that improve the clarity, portability, or reliability of the `anti-ui-slop` workflow and the local `ui-reference-mcp` backend.

Before opening a pull request:

1. Keep the skill concise and agent-agnostic.
2. Keep the local MCP backend free of provider credentials in the repository; credentials belong to the user configuration directory.
3. Do not add unsupported product claims or describe capabilities the fork's server does not implement.
4. Validate the skill metadata and test it on a real interface task.

For fork maintenance and support, use the maintainer profile [FlaBBB](https://github.com/FlaBBB) or the [fork repository](https://github.com/FlaBBB/uizze).
