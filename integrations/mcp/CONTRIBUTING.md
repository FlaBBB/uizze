# Contributing

This fork's local MCP server and its documentation are maintained by FlaBBB. Focused improvements to the local backend, provider integrations, onboarding, compatibility, or security are welcome.

## Before opening a pull request

1. Search existing issues and pull requests in [this fork](https://github.com/FlaBBB/uizze).
2. Keep the change scoped to one problem.
3. Verify every command, provider interaction, and client connection you change.
4. Do not commit API keys, Mobbin credentials, user data, private screenshots, generated credentials, or copied proprietary product content.
5. Preserve the free skill workflow; reference and material retrieval through the local MCP is optional.
6. Document only capabilities and provider metadata the implementation actually returns.

For a substantial new integration, open an issue first with the target client, expected workflow, security model, and a minimal verification plan.
